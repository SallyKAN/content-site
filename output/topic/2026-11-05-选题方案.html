今天 10:00 再跑一次 curl https://api.ipify.org（同环境）返回 155.117.84.236——和第 1103 晚那条附注里的 155.117.84.227 同段。说明：走代理时出口是 155.117.84.x 这一段，而且这个出口 IP 会漂。

这就解释了一切

  • 微信白名单卡的不是你家宽 IP，而是代理出口
  • 代理出口是池子，每次连接可能换尾号（.227 → .236）
  • 所以这七天填 IP 永远填不中 —— 不是微信的问题，是链路设计的问题

🔧 今天的建议（三选一，都只需要你做一次决定）

A｜换固定出口（推荐，一次性解决）
在代理客户端里把当前节点的「固定 IP / 静态住宅」打开，或换成有固定出口的节点，然后把那个固定 IP 填进微信白名单。之后永不再填。

B｜让脚本不走代理（最快，2 行代码）
给 publisher.py 的 session 加：

session.trust_env = False

或运行时 NO_PROXY='*' python3 publish_1029.py。微信看到的就是家宽真实 IP，填一次即可。
⚠️ 风险：家宽 IP 如果也是动态的（这七天变过三次），同样会漂。所以 A 更稳。
