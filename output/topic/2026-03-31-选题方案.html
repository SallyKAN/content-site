选题1：Harness-First Engineering — Datadog 如何用 AI Agent 写出生产级系统

日期：2026-03-31
状态：待写
审核分数：92/100

事件描述

Datadog 工程博客发布深度文章，分享他们用 AI coding agent（Claude Code + Codex）构建了 redis-rust（Redis 兼容服务器）和 Helix（Kafka 兼容流引擎）两个生产级系统。核心方法论是 "Harness-First Engineering"：不再逐行审查 agent 生成的代码，而是投资于自动化验证体系（确定性仿真测试 DST、TLA+ 形式化规约、Kani 有界证明、Maelstrom 线性化检查、生产流量影子测试），让 harness 做人类审查无法规模化的验证工作。

核心角度

"不是更好的 Agent，而是更好的笼子" — 当 Agent 的代码生成速度远超人类验证速度时，瓶颈从"写代码"转移到了"信任代码"。Datadog 给出的答案不是更聪明的模型，而是更严格的验证框架。这是一个范式级的思维转变：从 vibe-coding 到 harness-first。
