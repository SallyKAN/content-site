今早 10:00 实跑 python3 publish_1029.py（逐字未改）：

Exception: 获取access_token失败: {'errcode': 40164,
 'errmsg': 'invalid ip 183.23.195.97 ipv6 ::ffff:183.23.195.97,
 not in whitelist rid: 6aea91bb-1899ef69-30ff2f64'}

但同一分钟 curl https://api.ipify.org 返回：

210.6.40.25

这是六天来第一次出现两个不一致的地址。 前一天（11/03）两者都是 183.23.195.97，今天微信侧看到的是 183.23.195.97（旧地址），国内直连出口却是 210.6.40.25。

两种解释，都指向同一件事：
1. 请求没走本机直连——publisher.py 里的 requests 大概率走了一个代理/环境变量，微信看到的是代理出口 183.23.195.97；而 curl 未继承该代理，走的是真实出口 210.6.40.25。
2. 微信 token 接口有边缘节点缓存，回报的是上一次的 IP。

结论：填哪个 IP 都可能白填。 所以今天不给你 IP 列表了——除非先确认代理这件事。

检查一行即可（不需要碰后台）：

env | grep -i proxy

如果有 http_proxy / https_proxy / all_proxy，说明第 1 种解释成立，那么白名单该填的是代理的出口 IP，不是家宽 IP。
